## Cara Menjalankan Program

### 1. Web Platform
Buka file `hello.html` langsung pada peramban web (Google Chrome, Microsoft Edge, Mozilla Firefox) atau melalui live server:
```bash
# Atau klik ganda berkas hello.html di File Explorer
start hello.html
```

### 2. Node.js (Back-End)
Jalankan file `hello.js` menggunakan runtime Node.js:
```bash
node hello.js
```
*Output:*
```text
Hello, Node.js Platform!
```

### 3. Desktop (Java)
Kompilasi dan jalankan file `HelloDesktop.java`:
```bash
javac HelloDesktop.java
java HelloDesktop
```
*Output:*
```text
Hello, Desktop Platform!
```
